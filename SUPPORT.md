## Get Help

For questions, unexpected behavior, or feature requests, open an
[issue](https://github.com/jantielens/vscode-workspace-downloads/issues).

Include the following details so we can investigate:

* VS Code and Workspace Downloads versions
* Operating system and workspace type, such as local, Remote SSH, Dev Container,
  WSL, Remote Tunnel, or desktop Codespaces
* Selected workspace-relative paths or glob patterns
* Whether the destination was configured, remembered, or selected during the download
* Steps to reproduce the problem and the expected result
* Relevant error messages or `Workspace Downloads` output, with file contents,
  credentials, and private paths removed
